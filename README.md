## Мой рабочий процесс (Workflow):
1. Придумал идею во сне.
2. Спросил у ИИ: «Напиши мне это, пожалуйста».
3. Скопировал. Вставил. 
4. Работает? Значит, это не баг, а фича, заложенная самой Вселенной.
5. Сделал коммит с сообщением `fix: it works, don't touch`.
